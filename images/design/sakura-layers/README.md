# 벚꽃 레이어 8종

내장 image_gen 도구로 첨부한 참고 이미지의 분홍색 질감·주름·꽃잎 형태를 참고하여 제작했습니다.
각 PNG는 꽃잎 한 개와 실제 투명 배경을 갖습니다. 페이지에는 images/effects/sakura의 96px WebP를 사용합니다.

최종 프롬프트 요약: "단일 벚꽃잎 하나, 옅은 분홍색 사진·수채화 질감, 미세한 잎맥과 종이 같은 질감, 자연스러운 주름, 전체 형태가 잘리지 않게 중앙 배치, 실제 알파 투명 배경, 격자·텍스트·다른 꽃잎 없음."
01 대각선 아래끝 / 02 위쪽으로 긴 형태 / 03 가로형 / 04 곡선형 / 05 아래로 긴 형태 / 06 접힌 가로형 / 07 세로 물방울형 / 08 왼쪽 아래끝 형태.

원본 PNG는 복원·편집용으로 보관하고 공개 배포 파일에는 포함하지 않습니다.
